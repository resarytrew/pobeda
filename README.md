# Зачёт Победы

Информационный лендинг об интерактивной военно-исторической игре-хронике Оренбургского президентского кадетского училища.

**Адрес сайта после публикации GitHub Pages:** https://resarytrew.github.io/pobeda/

## Развёртывание в репозитории resarytrew/pobeda

1. Загрузите `index.html`, папку `assets`, файл `.nojekyll` и каталог `.github/workflows` в корень ветки `main` (или `master`).
2. Откройте GitHub → `Settings` → `Pages` → `Build and deployment` → `Source` и выберите **GitHub Actions**.
3. После успешного выполнения процесса `Публикация «Зачёт Победы» в GitHub Pages` лендинг будет доступен по адресу выше.

Можно использовать `deploy.ps1` для автоматического копирования файлов в GitHub: для этого нужен установленный Git и действующий вход в GitHub на компьютере.

## Состав

- `index.html` — адаптивная страница, стили, сценарии интерактивных элементов.
- `assets/` — локальные изображения, видео, учебное пособие PDF.
- `.github/workflows/pages.yml` — автоматическая публикация изменений в GitHub Pages.
- `.nojekyll` — отключение обработки Jekyll.

Внешние ссылки на первоисточники открываются отдельно. На сайте нет серверной части, базы данных и необходимости собирать фронтенд.
